# Capturas del prototipo en ejecución

Pantallas de la plataforma recorridas con las cuentas de demostración. Los datos son sintéticos: no corresponden a personas reales.

| Carpeta | Contenido |
| --- | --- |
| `web/` | Vista de escritorio, por rol |
| `movil/` | Vista móvil, por rol. Las pantallas largas van por partes |
| `api/` | Estado del servicio en el navegador y en JSON |
| `documentos_generados/` | Páginas de los PDF y del Excel que descarga la plataforma |
