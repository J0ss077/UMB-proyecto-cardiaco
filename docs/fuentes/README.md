# Documentos fuente

Los documentos que aporta el socio y de los que salen el esquema, el diccionario de datos y
las referencias del manual académico. Se guardan aquí, fuera de la raíz del repositorio, para
que la raíz quede con el código y la documentación propia del proyecto.

| Archivo                        | Qué es                                                                                     |
| ------------------------------ | ------------------------------------------------------------------------------------------ |
| `manual-tecnico-v01.pdf`       | Primera versión del manual técnico. Fijó las dieciséis tablas y los siete tipos enumerados |
| `manual-tecnico-v02.pdf`       | Versión vigente del manual técnico. Conserva las dieciséis tablas y los siete enumerados   |
| `documentacion-semestre-1.pdf` | Documentación académica del primer semestre                                                |
| `documentacion-semestre-2.pdf` | Documentación académica del segundo semestre                                               |

El texto extraído de los manuales se usa como material de trabajo y no se versiona: vive en
`.recon/`, que está fuera del historial. Lo que el repositorio afirma sobre el modelo de
datos está en `docs/manual/modelo-de-datos.md` y en `db/migrations/0001_initial.sql`, no en
estos PDF.
